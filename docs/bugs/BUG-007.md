# BUG-007 — Diseño tipo agenda en «Agenda del día»

- **Zona:** reservas
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** codex

## Descripción
La «Agenda del día» de «Mis reservas» tiene un diseño plano.

## Resultado esperado
Rediseño con aspecto de agenda física: hoja con líneas, franjas horarias en el margen y reservas anotadas como apuntes a mano (fuente manuscrita o similar). Debe respetar el modo claro/oscuro y verse bien en móvil.

## Archivos probables
src/components/Reservas.jsx y su CSS

## Solución
Causa: las reservas se mostraban como tarjetas planas. Archivo: `src/styles/reservas.css`. Se añade una hoja pautada con margen horario, tipografía manuscrita disponible en el dispositivo, colores del tema y columnas que permiten ajustar textos en móvil.

Verificación: `npm test` y `npm run build` pasan. Rama: `fix/codex-bugs`.

Revisión visual aislada en escritorio y móvil de 390 px, en claro y oscuro. Se ajustó la posición de las líneas para que queden bajo el texto y el color de las horas al token `--verde`, legible en ambos temas.
