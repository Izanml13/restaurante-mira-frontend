# BUG-017 — Chatbot MIRASI: idioma, autoscroll y número de recomendaciones

- **Zona:** mira
- **Prioridad:** alta
- **Estado:** pendiente
- **Asignado:** claude

## Descripción
1) El primer mensaje del chatbot no sale en el idioma de la web. 2) Mientras la IA escribe, no se baja solo y hay que hacer scroll a mano. 3) Siempre recomienda 5 restaurantes.

## Resultado esperado
1) El saludo inicial en el idioma activo (es/ca/en). 2) Autoscroll hacia abajo mientras llega la respuesta, salvo si el usuario ha subido a propósito. 3) Recomienda el número que pide el usuario (si pide 2, 2; si duda entre 3, 3); 5 solo como máximo por defecto.
