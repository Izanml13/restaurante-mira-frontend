# BUG-005 — Filtro del mapa: solo las 4 comarcas

- **Zona:** mapa
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** claude

## Descripción
El filtrado del mapa incluye también provincias.

## Resultado esperado
El filtro muestra únicamente las 4 comarcas, sin opciones de provincia.

## Archivos probables
src/components/Mapa.jsx, RestaurantMap.jsx

## Solución
- **Causa:** la API real no envía `zona` y el frontend la construye como `"<ciudad>, Spain"`. El mapa creaba un botón de filtro por cada valor distinto: además de las 4 zonas salían Gerona, Lerida, Lérida, Salou, Salt, Vila-seca… (36 poblaciones en los datos de producción).
- **Cambio:** nueva función `zonaPrincipal(r)` en `services/cityCenters.js`, que mantiene la zona si es una de las 4 y, si no, asigna el local a la más cercana según sus coordenadas. `Mapa.jsx` la usa para los contadores y el filtro, y muestra solo `ZONAS_CATALUNA`. La ficha emergente del pin sigue mostrando la población real. Test nuevo: `test/zonaPrincipal.test.js`.
- **Verificación:** `npm test` (143 ok), `npm run build` ok. Con los 704 locales de `/v1/restaurants/mapa` de producción, todos quedan en una de las 4 zonas (Barcelona 246, Tarragona 205, Girona 173, Lleida 80) y no se pierde ninguno. En el navegador (mock API) aparecen solo «Todas» y las 4 zonas, y el filtro funciona. No se ha podido abrir el mapa contra producción desde localhost porque la API bloquea el origen (CORS).
- **Nota:** se interpreta «4 comarcas» como las 4 zonas de la app (Barcelona, Tarragona, Girona, Lleida). Si se refiere a 4 comarcas concretas (Tarragonès, Gironès…), hay que cambiar `CENTROS_CIUDAD`.
