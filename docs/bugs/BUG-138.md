# BUG-138 — El APK falla al consultar isAvailableAsync

- **Zona:** app
- **Prioridad:** alta
- **Estado:** en revisión
- **Asignado:** codex
- **Rama:** `fix/codex-apk-138-145`
- **Fecha:** 2026-10-16

## Descripción
En el APK aparece de forma intermitente «MIRA: Cannot read property isAviableAsync of undefined». En el código la llamada se escribe `isAvailableAsync` y aparece en las exportaciones CSV. La pantalla debe seguir funcionando aunque compartir no esté disponible.

## Solución
La importación `import { Sharing } from 'expo-sharing'` devolvía `undefined`: el SDK exporta funciones, no ese objeto. Afectaba a la exportación CSV de Dashboard y Ops.

Se carga el namespace con `import('expo-sharing')` dentro de la operación protegida. `compartirArchivo` comprueba `modulo?.isAvailableAsync?.()` y `shareAsync`, captura también el fallo al cargar el módulo nativo y devuelve disponibilidad sin propagar una excepción a la pantalla. Si no se puede compartir, se muestra un aviso.

Pruebas: módulo ausente/incompleto, carga nativa fallida, API no disponible, exportación correcta y rechazo de compartir. Revisado contra [Expo Sharing 57](https://docs.expo.dev/versions/v57.0.0/sdk/sharing/).
