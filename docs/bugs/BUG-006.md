# BUG-006 — «Mis reservas» debe abrirse siempre arriba

- **Zona:** reservas
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** codex

## Descripción
Si sales de «Mis reservas» a mitad de scroll y vuelves, mantiene la posición anterior.

## Resultado esperado
Al entrar en «Mis reservas» la vista empieza siempre en la parte superior.

## Archivos probables
src/components/Reservas.jsx, App.jsx (cambio de vista)

## Solución
Causa: el reinicio del hash podía ocurrir antes de montar la nueva vista. Archivo: `src/components/Reservas.jsx`. Se reinicia el scroll mediante `useLayoutEffect` en cada montaje, también al entrar directamente.

Verificación: `npm test` y `npm run build` pasan. Rama: `fix/codex-bugs`.

Prueba en navegador con el componente real montado en una página aislada: tras desplazar hasta 844 px, salir y volver a montar, `window.scrollY` vuelve a 0. No requiere sesión ni datos reales.
