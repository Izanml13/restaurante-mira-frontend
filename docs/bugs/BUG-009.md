# BUG-009 — Icono del ojo de la contraseña roto en el registro

- **Zona:** registro
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** claude

## Descripción
Al crear cuenta, el botón del ojo para mostrar u ocultar la contraseña funciona mal.

## Resultado esperado
El ojo se ve bien colocado dentro del campo, alterna mostrar/ocultar en cada campo de contraseña (contraseña y repetir) y el icono cambia según el estado. Revisar también Login y Restablecer si comparten el componente.

## Archivos probables
src/components/Registro.jsx, Login.jsx, Restablecer.jsx, styles/cuenta.css

## Solución
- **Causa:** el botón usaba emojis (👁️ / 🙈). Cambian de forma y tamaño según el sistema: en Windows el ojo sale solo y el mono no se parece a «ocultar». Además, Edge añade su propio ojo nativo (`::-ms-reveal`) y salían dos, y al pulsar el botón el campo perdía el foco (en móvil se cerraba el teclado).
- **Cambio:** en `Registro.jsx`, el componente `IconoOjo` es un SVG que usa el color del tema (ojo, y ojo tachado cuando la contraseña está visible), y `onMouseDown` evita que el campo pierda el foco. En `cuenta.css`, el botón queda centrado con flex, gris por defecto y verde al pasar el ratón o cuando está activo, y se oculta el ojo nativo de Edge.
- **Alcance:** solo el registro tiene este botón. Login no tiene ojo, y Restablecer usa un checkbox «mostrar contraseña» que funciona.
- **Verificación:** `npm test` (146 ok), `npm run build` ok. En el navegador a 375 px, en oscuro y con clics reales, alterna oculto/visible, el icono cambia y el foco se queda en el campo.
