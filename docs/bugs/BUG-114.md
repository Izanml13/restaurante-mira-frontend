# BUG-114 — Botón en modo oscuro no se oscurece al pasar el cursor

- **Zona:** tema
- **Prioridad:** baja
- **Estado:** en revisión
- **Asignado:** claude
- **Rama:** fix/claude-tanda4

## Pasos para reproducir
1. Activar el modo oscuro.
2. Pasar el cursor por encima de un botón (principal/primario).

## Resultado esperado
El botón se oscurece más al hacer hover, con feedback visual claro de la interacción.

## Resultado actual
El botón apenas cambia o mantiene el mismo tono; no se percibe el hover.

## Notas / capturas
Hallazgo del usuario tras la tanda 3. El botón «Ver más información» de las cards usa `.btn-cta` (`src/App.css`), cuyo hover cambia el fondo a `var(--primary)`.

## Solución

Causa: en modo oscuro `--primary` es `#a8d5ba` (verde claro pensado para texto sobre fondo oscuro), así que al pasar el cursor el botón se aclara y el texto blanco pierde legibilidad. En claro `--primary` es más oscuro que `--primary-container`, por eso allí el hover sí oscurece. Archivo: `src/App.css`. Añadida la regla `[data-theme='dark'] .btn-cta:hover` con `background: color-mix(in srgb, var(--primary-container) 78%, #000)`, que oscurece el verde del botón en oscuro sin tocar el tema claro (afecta a todos los `.btn-cta`: cards, ficha, JAM, MIRASI). Verificación: `npm test` 167/167 y `npm run build` OK en `fix/claude-tanda4`. Pendiente de revisión.
