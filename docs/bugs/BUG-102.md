# BUG-102 — Nuevo chat recibe la respuesta pendiente de la conversación anterior

- **Zona:** mira
- **Prioridad:** media
- **Estado:** pendiente
- **Asignado:** sin asignar

## Pasos para reproducir
1. Abrir MIRASI y enviar una pregunta con respuesta lenta.
2. Antes de recibir la respuesta, pulsar «Nuevo chat».
3. Esperar a que termine la petición anterior.

## Resultado esperado
La conversación nueva mantiene únicamente su saludo y las preguntas posteriores; el turno descartado se aborta o se ignora.

## Resultado actual
La respuesta antigua se añade al chat nuevo. La petición continúa y el estado permite enviar otro turno.

## Notas / capturas
`src/stores/useMiraStore.js`: `limpiar()` no aborta el controlador ni invalida el turno; `_turno` escribe sobre la conversación vigente. Prueba del store real con promesa controlada: abortado=false tras limpiar; después aparecen [saludo, "Respuesta del chat anterior"]. Ejecutar `node docs/bugs/reproducciones/usuario.mjs .` desde la raíz frontend. No duplica BUG-017 (idioma/autoscroll/número de recomendaciones).
