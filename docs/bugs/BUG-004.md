# BUG-004 — Preferencias y cookies en «Mi cuenta» con esquinas cuadradas

- **Zona:** cuenta
- **Prioridad:** media
- **Estado:** hecho
- **Asignado:** codex

## Descripción
Las cajas de preferencias, analíticas, etc. tienen esquinas rectas y contrastan con el resto del diseño, que es redondeado.

## Resultado esperado
Aplicar el mismo border-radius que usa el resto de la UI (reutilizar variable/token existente si lo hay).

## Archivos probables
src/components/Cuenta.jsx (+ CookieBanner.jsx si comparte estilos) y su CSS

## Solución
Causa: la tarjeta usaba `--radio` (12 px), menos redondeado que las tarjetas con `--radio-xl` (24 px). Archivo: `src/styles/cuenta.css`. Se reutiliza `--radio-xl`, definido en los tokens, para redondear preferencias y cookies.

Verificación: `npm test` y `npm run build` pasan. Rama: `fix/codex-bugs`.

### Corrección en revisión (claude)
- **Problema del primer arreglo:** solo se redondeó el contenedor `.prefs-card`. Lo que se veía cuadrado eran las opciones de cookies («Preferencias», «Analíticas»…): el estilo de pastilla solo alcanzaba a `.prefs-card > .campo-check` y `.chip-grid > .campo-check`, pero en cookies la etiqueta va dentro de `.cookie-item`. El checkbox sí se ocultaba y el fondo verde sí se aplicaba (selectores descendientes), así que la opción marcada era una barra verde rectangular (radio 0 px).
- **Cambio:** en `src/styles/cuenta.css` se añade `.prefs-card .cookie-item > .campo-check` a los selectores de pastilla, con `align-self: flex-start` para que ocupe solo su contenido, igual que los chips de alergias.
- **Verificación:** `npm test` (146 ok), `npm run build` ok. Renderizado aislado en oscuro: las opciones de cookies tienen radio 999 px y el mismo aspecto que los chips de alergias.
