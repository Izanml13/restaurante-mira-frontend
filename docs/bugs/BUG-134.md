# BUG-134 — De admin no cabe todo en el header («MIRAPP» ocupa demasiado)

- **Zona:** header
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** opencode
- **Rama:** fix/errores-ui-web

## Pasos para reproducir
1. Entrar con un usuario admin (o empresa).
2. Abrir la web en una pantalla de portátil (1280–1440 px).

## Resultado esperado
Todos los elementos del header caben sin desbordar; si falta espacio, todo se comprime un poco.

## Resultado actual
Con la sesión de admin se añaden Admin, Mi panel, cuenta y salir, y dejaba de caber: la fila se desbordaba/recortaba.

## Notas / capturas
Hallazgo del usuario: «MiraAPP hace que cuando eres admin no quepa todo en el header, cámbialo a App o que se apriete todo un poco cuando no hay espacio».

## Solución
- **Cambio i18n:** `nav.app` de «MIRAPP» a «App» en `src/i18n/es.js`, `ca.js` y `en.js` (solo la línea 9; «Descarga MIRAPP» de la sección de descarga intacta).
- **Cambio CSS (`src/App.css`):** el header es una sola fila en escritorio; se añaden media queries de compresión para `min-width: 768px`:
  - hasta 1439 px: huecos (`.site-header`, `.nav-list`, `.header-cuentas`) y tipografía más apretados;
  - hasta 1199 px: más compresión, nombre de cuenta con `max-width: 5rem` y texto de «Salir» oculto (queda el icono con `aria-label`);
  - hasta 919 px: nombre de cuenta oculto y texto de los enlaces de panel oculto (ambos conservan `title` como nombre accesible).
- **Verificación:** `npm test` (238 ok), `npm run build` correcto.
