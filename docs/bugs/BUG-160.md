# BUG-160 — Scrolls independientes y modo oscuro del perfil

- **Zona:** cuenta
- **Prioridad:** media
- **Estado:** en revisión

## Pasos para reproducir
1. `#/cuenta` en escritorio con una ventana baja: la ficha izquierda (sticky) no se puede desplazar y su parte inferior queda inaccesible.
2. Activar el modo oscuro: superficies planas casi negras, franja verde muy saturada.

## Resultado esperado
Cada columna se desplaza por su cuenta; modo oscuro con jerarquía de superficies y acentos contenidos.

## Resultado actual
Ficha cortada; contraste y paleta poco cuidados en oscuro.

## Notas / capturas

## Solución
- `src/styles/cuenta.css`, ≥861px: `.cuenta-perfil` con `max-height: calc(100svh - 7rem)`, `overflow-y: auto`, `overscroll-behavior: contain` y scrollbar fina. La columna derecha sigue el scroll de la página. En ≤860px no hay scroll interno.
- Modo oscuro (solo `[data-theme='dark'] .cuenta-pagina`): superficies verdosas escalonadas (fondo `--fondo` < tarjeta `#171c19` < elevada `#1e2521`), bordes `rgba(168,213,186,.12)`, franja `#24463a→#1c3a30`, texto secundario `#b3bcb6` (≈9:1), saldo dorado apagado `#e8cf7a`, chips con hover/seleccionado visibles (`#2f5a4a` con blanco ≈7:1). El modo claro no cambia.
- Verificado en el navegador con un arnés temporal (no incluido): rueda sobre la ficha → `perfil.scrollTop` 396, página 0; rueda sobre la derecha → página 500, ficha intacta. Capturas claro/oscuro. `npm test` y `npm run build` en verde.
