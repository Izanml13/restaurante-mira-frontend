# BUG-155 — Botón de hamburguesa para el menú lateral del admin

- **Zona:** admin/ux
- **Prioridad:** media
- **Estado:** hecho

## Pasos para reproducir
1. Entrar en `#/admin` en escritorio: el menú lateral solo se abre pasando el ratón por el borde izquierdo.

## Resultado esperado
El hover sigue funcionando y, además, un botón ☰ en la esquina superior derecha de la cabecera abre/cierra el menú.

## Resultado actual
Solo había botón de menú en pantallas ≤ 1024 px y a la izquierda de la cabecera.

## Notas / capturas

## Solución
- `src/components/ops/OpsPanel.jsx`: el botón existente `.ops-menu-btn` (que conmutaba `menuMovil`) se mueve al final de la cabecera y se muestra siempre, con `aria-expanded`, `aria-controls="ops-sidebar"` y `aria-label`; el `<aside>` recibe `id="ops-sidebar"`. Así no hay botón duplicado en móvil.
- `src/styles/ops.css`: se quita el `display: none` (y el `display: grid` de ≤1024 px) y se añade `:focus-visible`. El hover (`.ops-sidebar-trigger`, `.pinned`) no cambia.
- Verificado: `npm test` y `npm run build`. No verificado visualmente: el panel admin requiere sesión real.
