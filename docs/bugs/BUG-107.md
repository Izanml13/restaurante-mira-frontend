# BUG-107 — Liquidación CSV marca los tickets de no-show como asistencia sí

- **Zona:** dashboard/fiscal
- **Prioridad:** media
- **Estado:** pendiente
- **Asignado:** sin asignar

## Pasos para reproducir
1. Tener un ticket con `asistio:false` asociado a un no-show.
2. Abrir el dashboard del restaurante y exportar liquidación.
3. Consultar la columna «Asistio» de ese ticket.

## Resultado esperado
La columna refleja la asistencia persistida: «no».

## Resultado actual
Todas las filas se exportan como «si», también los no-show.

## Notas / capturas
`src/components/dashboard/Dashboard.jsx`, handleExportLiquidacion: construcción de CSV escribe literalmente `si`, sin leer asistio. Prueba reproducible desde la raíz frontend: `node docs/bugs/reproducciones/paneles.mjs . ../codex-tanda2-backend`. Extrae las funciones reales y simula únicamente la descarga, sin API remota ni escrituras. Ticket no-show produjo fila terminada en `;si`. Causa distinta del filtro de periodo y de la truncación, por eso se registra aparte.
