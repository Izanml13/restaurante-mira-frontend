# BUG-020 — Header: mostrar solo el nombre del usuario

- **Zona:** header
- **Prioridad:** baja
- **Estado:** en revisión
- **Asignado:** claude

## Descripción
En el header aparece «Mi cuenta» junto al nombre.

## Resultado esperado
En el header se ve directamente el nombre del usuario (sin «Mi cuenta»), sin perder el acceso a la cuenta ni la accesibilidad (aria-label).

## Archivos probables
src/components/Header.jsx

## Solución
- **Cambio:** `Header.jsx` quita el texto «Mi cuenta» del enlace de cuenta y deja el icono más el nombre (o el email si no hay nombre). El enlace mantiene `aria-label` «Mi cuenta: <nombre>» para lectores de pantalla. En `App.css`, `.header-cuenta-nombre` pasa de gris secundario a color principal y peso 600, porque ahora es la etiqueta.
- **Verificación:** `npm test` (146 ok), `npm run build` ok. **Pendiente de ver con sesión iniciada:** el enlace solo aparece con usuario logueado y no hay credenciales de prueba en el repo.
