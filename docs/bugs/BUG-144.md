# BUG-144 — El chat del agente MIRA no está en la app

- **Zona:** app
- **Prioridad:** media
- **Estado:** hecho
- **Asignado:** codex
- **Rama:** `fix/codex-apk-138-145`
- **Fecha:** 2026-10-16

## Descripción
El APK no ofrece el chat del agente MIRA que existe en la web. Se necesita una pantalla accesible desde el menú y conectada a la misma API, con una versión mínima si no se porta toda la interfaz.

## Solución
Versión mínima nativa en `/mira`, accesible como «MIRA SI» desde el menú. Usa el endpoint real de la web, `POST /v1/ai/agent`, con el mismo cuerpo, idioma, historial limitado, token opcional e Idempotency-Key UUID de Expo Crypto. El cliente HTTP conserva la autenticación obligatoria del resto de llamadas y acepta AbortSignal.

Incluye respuestas de texto, confirmación explícita mediante `needsConfirm.confirmId`, cancelar, parar, nuevo chat, errores de acciones dentro de HTTP 200, errores de red/401/429 y timeout de 35 s. Reintentar conserva cuerpo y clave; la confirmación inicia otro paso con clave nueva. La conversación queda en memoria, se borra al cambiar de cuenta y las respuestas tardías se ignoran.

Textos en es/ca/en. Pruebas de contrato frente a la web, confirmación/cancelación, idempotencia, cambio A→B, parada, cliente HTTP y errores. UUID revisado en [Expo Crypto 57](https://docs.expo.dev/versions/v57.0.0/sdk/crypto/).

Pendiente para paridad completa: tarjetas enriquecidas de restaurantes/reservas/puntos y sus accesos contextuales, renderizado Markdown y reintentos automáticos de la respuesta `retryable`. Esta versión muestra texto y usa reintento manual; no incluye el launcher flotante de la web.
