# BUG-146 — Los skeletons de la landing se ven pegados

- **Zona:** landing
- **Prioridad:** baja
- **Estado:** en revisión
- **Asignado:** opencode
- **Rama:** `fix/tanda2-ui`
- **Fecha:** 2026-10-19

## Descripción
Mientras la landing carga los restaurantes, las barras del skeleton quedaban
apiñadas: entre 3 y 6 px de separación entre barras de 12–16 px. El cuerpo se
veía como un bloque compacto arriba y dejaba un hueco vacío grande debajo, muy
distinto del ritmo de una card real.

## Solución
Solo CSS, sin tocar el JSX:

- `.skeleton-card .card-cuerpo`: `gap` de `0.25rem` a `0.5rem` y
  `padding-top` de `1.15rem`.
- Barras de descripción a `0.8rem` y título a `1.1rem`.
- `.skeleton-actions` con `margin-top: auto` y `padding-top`, para que los
  botones queden anclados al fondo igual que en la card real.

## Validación
- Medido en producción retrasando la API para capturar el estado de carga:
  huecos entre barras de 8–17 px (antes 3–6) y acciones al fondo.
- `npm test`: 309/309.
- `npm run build`: correcto.
