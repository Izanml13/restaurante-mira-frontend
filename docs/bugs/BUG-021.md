# BUG-021 — Auditoría general de bugs de la web

- **Zona:** general
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** codex

## Descripción
Revisión general de la web en busca de bugs no reportados.

## Resultado esperado
Usar subagentes de Codex para recorrer la web por zonas. NO arreglar nada: por cada bug real encontrado, crear una ficha BUG-1XX.md (desde BUG-101) con pasos para reproducir, y listarla en BUGS.md como «pendiente» sin asignar, para repartirlos después.

## Archivos probables
toda la web

## Solución

Auditoría delegada en tres subagentes Codex, sin aplicar correcciones: auditoria_catalogo (buscador/cards, ficha/carta, mapa); auditoria_usuario (reservas, cuenta/puntos, mensajería, MIRASI); auditoria_paneles_movil (admin/ops, dashboard restaurante y web a390 px). Leídos índice/fichas001–021 para descartar duplicados.

Hallazgos nuevos: BUG-101 disponibilidad ficticia al fallar consulta; 102 respuesta antigua en chat nuevo; 103 lista de espera oculta errores al quitar; 104 navegación de canje/historial cruzada; 105 CSV ignora mes; 106 CSV truncado a20 tickets; 107 no-show exportado como asistencia; 108 contadores de hoy duplicados; 109 dashboard desborda a390px; 110 búsqueda de cabecera Ops no recarga. Diez fichas según plantilla, pendientes y sin asignar en BUGS.md. Se limita BUG-106 al CSV efectivamente ejecutado; posible impacto en factura queda anotado para comprobar.

Verificación: scripts de funciones/store/handler reales conservados en docs/bugs/reproducciones/usuario.mjs y paneles.mjs, ambos ejecutados también por padre; interacciones locales con componentes reales, API simulada y fallos de red controlados. Padre confirma 4/4 plazas libres ante error, ancho845 en viewport390 y búsqueda que solo filtra con botón local. Capturas temporales indicadas en fichas. No cuentas/reservas/mutaciones de producción. Se excluyeron errores debidos a muestras incompletas y bugs ya cubiertos, además de una regresión introducida en BUG014 que se corrigió y plegó en su propio commit.

Archivos de este bug: docs/bugs/BUG-021.md, BUGS.md, BUG-101.md a BUG-110.md y los dos scripts de reproducción. Sin cambios productivos de BUG021. Verificación global: npm test frontend148/148 y npm run build pasan; backend217/217 tras último ajuste BUG014. Pendiente: repartir y corregir los diez bugs reportados; revisión de esta tanda.
