# BUG-105 — Exportar liquidación de Este mes incluye tickets de otros meses

- **Zona:** dashboard/fiscal
- **Prioridad:** media
- **Estado:** pendiente
- **Asignado:** sin asignar

## Pasos para reproducir
1. Tener un ticket del mes actual y otro del mes anterior en el restaurante.
2. Abrir el dashboard y seleccionar «Este mes».
3. Pulsar «Exportar Liquidación» y abrir el CSV.

## Resultado esperado
El CSV contiene únicamente los tickets del mes seleccionado.

## Resultado actual
El archivo contiene tickets de ambos meses, aunque se presenta como liquidación del mes actual.
