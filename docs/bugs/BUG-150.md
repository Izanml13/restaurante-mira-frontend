# BUG-150 — No se puede cambiar el idioma desde Ajustes del admin

- **Zona:** admin / ajustes
- **Prioridad:** baja
- **Estado:** en revisión
- **Asignado:** opencode
- **Rama:** `fix/tanda2-ui`
- **Fecha:** 2026-10-19

## Descripción
El panel de operadores no ofrecía ningún selector de idioma. Para cambiar
entre español, catalán e inglés había que volver a la web o tocar el selector
del header.

## Solución
- Fila «Idioma» en `OpsAjustes`, encima de «Sesión».
- `<select class="ops-selectbox">` enlazado a `useI18n()` (`lang`, `setLang`,
  `available`), con `aria-label` traducido.
- Nuevas claves con paridad es/ca/en: `ops.idioma` y `ops.idiomaAyuda`.
- El cambio usa el mismo mecanismo que el resto de la app: se guarda en
  `mira_lang` y actualiza toda la interfaz al instante.

## Validación
- Banco de pruebas con `ops.css` real: selector visible de 92×40 px, con las
  tres opciones y la clase `ops-selectbox`.
- `npm test`: 309/309 (incluye paridad de claves i18n).
- `npm run build`: correcto.
