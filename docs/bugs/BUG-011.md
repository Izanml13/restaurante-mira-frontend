# BUG-011 — Botón «Marcar todo como leído» en mensajería

- **Zona:** mensajes
- **Prioridad:** media
- **Estado:** en revisión
- **Asignado:** codex

## Descripción
En la mensajería no hay forma de marcar todos los mensajes como leídos de una vez.

## Resultado esperado
Botón «Marcar todo como leído» visible solo si hay mensajes sin leer. Al pulsarlo se marcan todos como leídos en el backend y el contador de no leídos del header/BottomNav se actualiza a 0. Si el backend no tiene endpoint para ello, añadirlo en el repo del backend.

## Archivos probables
src/components/Mensajes.jsx, servicio de mensajes, recargarMensajes en App; backend: módulo mensajes

## Solución

Reproducción: PUT /v1/mensajes/read-all devolvía 404 y el buzón solo ofrecía lectura individual. Causa: faltaban endpoint y acción masiva. Archivos: Mensajes.jsx, services/mensajesApi.js, i18n/es.js/ca.js/en.js, test/mensajesTodos.test.js; backend mensajes/routes.js, mensajes/service.js, test/mensajesTodos.test.js y docs/api.md. Botón condicionado a mensajes no leídos, bloqueo durante la petición, actualización local y callback existente onLeidos/recargarMensajes del header. BottomNav no tiene contador de mensajes en esta versión. Backend filtra por UID del token y procesa 505 mensajes en lotes sin afectar a otro usuario. Verificación: reproducción fallida antes, 148 tests frontend, build correcto y 197 tests backend tras el cambio. Contrato nuevo sin body documentado; desplegar backend primero y frontend después. Pendiente: revisión.
